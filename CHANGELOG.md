# Changelog

## 0.1.0 — 2026-08-03

- Local HTTP capture endpoints with named channels.
- Real-time dashboard updates through Server-Sent Events.
- Atomic local JSON persistence and configurable retention.
- Payload, raw body, query and header inspection.
- Automatic redaction of common authentication headers.
- GitHub, Stripe and generic HMAC signature verification.
- Request replay with delay simulation and replay history.
- Built-in GitHub, Stripe, Telegram and generic test events.
- Responsive DUONIQ interface.
- Docker, Compose and GitHub Actions support.
- Zero runtime dependencies.
